# ⌨️ Typing Challenge

A simple and interactive typing practice web app to improve typing speed and accuracy.

## 🚀 Live Demo
https://typingchallengev1.netlify.app/

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## ✨ Features
- Interactive typing practice
- Clean and user-friendly interface
- Helps improve typing speed and accuracy

## 💻 Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/sagarkumard007-cmyk/Typing-Challenge-.git
   ```
2. Open `index.html` in your browser.
